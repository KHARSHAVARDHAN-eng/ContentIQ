# Deployment Guide - contentIQ 🚀🎒

This guide provides step-by-step instructions to deploy **contentIQ** (FastAPI backend, React frontend, PostgreSQL database, Qdrant vector database, and S3-compatible cloud file storage) to production.

---

## 1. Required Infrastructure Accounts
Before starting, ensure you have active accounts on the following platforms:
1. **GitHub:** To host the remote code repository and trigger build pipelines.
2. **Vercel:** To host the React static frontend (Free tier is sufficient).
3. **Render** (or Railway): To host the FastAPI backend and managed PostgreSQL database.
4. **Qdrant Cloud:** To host the production semantic search cluster (Free Tier provides 1 cluster with 1GB RAM/0.5vCPU, which is sufficient for RAG processing).
5. **Supabase** (or AWS S3 / Cloudinary): To host uploaded PDF documents in a public/private bucket.

## 3. Step-by-Step Deployment Procedure

### Step 1: Connect Git Remote & Push Code
1. Open a terminal in the project root directory.
2. Initialize or verify your git repository branch:
   ```bash
   git status
   ```
3. Set your remote GitHub repository URL:
   ```bash
   git remote add origin https://github.com/your-username/your-repository-name.git
   ```
4. Stage and commit all files:
   ```bash
   git add .
   git commit -m "chore: prepare for production deployment"
   ```
5. Push your branch to GitHub:
   ```bash
   git push -u origin stable-redesign-v2
   ```

### Step 2: Configure Cloud Storage (Supabase example)
1. Go to **Supabase Console** -> Storage.
2. Create a new public bucket named `contentiq-uploads`.
3. Go to **Project Settings** -> **Storage**.
4. Enable S3-compatible access and copy the:
   - Endpoint URL
   - Access Key ID
   - Secret Access Key

### Step 3: Configure Qdrant Cloud
1. Go to **Qdrant Cloud Console** and provision a free cluster.
2. Copy the HTTPS endpoint (e.g. `https://xxx.aws.qdrant.io:6333`).
3. Generate an API Key and copy it.

### Step 4: Deploy Database & Backend to Render
1. Go to **Render Dashboard** -> **Blueprints**.
2. Connect your GitHub repository. Render will automatically read the `render.yaml` file.
3. Configure the required environment variables when prompted in the Render UI (Gemini API Key, Qdrant URL, S3 credentials, etc.).
4. Click **Apply**. Render will:
   - Create a managed PostgreSQL database.
   - Deploy Qdrant container as a private service.
   - Build and start the FastAPI Python server.
5. Copy the public URL of the backend (e.g., `https://documentiq-backend.onrender.com`).

### Step 5: Migrate Data from SQLite to PostgreSQL
Once the Render backend and PostgreSQL database are online:
1. Retrieve the PostgreSQL `connectionString` (DATABASE_URL) from the database settings page in Render.
2. Run the migration script locally to sync all existing user accounts, documents, study tools, chat logs, and study packs:
   ```bash
   cd backend
   python app/scripts/migrate_db.py sqlite:///./documentiq.db postgresql://user:password@host:port/dbname
   ```
3. The script will automatically connect to both databases, create PostgreSQL tables, and copy your data safely.

### Step 6: Deploy Frontend to Vercel
1. Go to **Vercel Dashboard** -> **Add New Project**.
2. Connect your GitHub repository.
3. Select the `frontend` folder as the root directory.
4. Set the **Framework Preset** to **Vite**.
5. Add the environment variable:
   - Key: `VITE_API_URL`
   - Value: `https://your-backend.onrender.com/api`
6. Click **Deploy**. Vercel will build and serve the application with secure SSL (HTTPS).

## 4. E2E Feature Verification Checklist

Once the URLs are live, test the following sequence:
- [ ] **Registration:** Sign up a new account.
- [ ] **Login:** Sign in with the credentials.
- [ ] **Upload File:** Upload a PDF document and verify it uploads to your S3 storage bucket.
- [ ] **Ingestion Pipeline:** Verify that the status moves to `PROCESSING` and eventually `INDEXED`.
- [ ] **Search Playground:** Verify that search queries return page-attributed matches.
- [ ] **Grounded Copilot:** Query a document inside the chat thread and check if responses contain verified citations.
- [ ] **Study Tools:** Generate Flashcards, MCQs, and Mind Maps. Flip flashcards and verify pan/zoom on the mindmap.
- [ ] **Study Packs:** Click "Generate Pack", verify that a unified PDF download works, and download the ZIP bundle to check its contents.
- [ ] **Evaluation Console:** Check RAG retrieval metrics.
